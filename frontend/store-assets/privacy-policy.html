Kasir Online ("kami", "aplikasi") berkomitmen untuk melindungi privasi Anda. Kebijakan ini menjelaskan jenis data yang dikumpulkan, cara penggunaannya, dan hak-hak Anda sebagai pengguna. Dengan menggunakan aplikasi ini, Anda menyetujui kebijakan ini.

📋

1. Informasi yang Kami Kumpulkan

a. Data Akun

Saat mendaftar atau menggunakan aplikasi, kami mengumpulkan:

  • Nama lengkap pemilik / pengelola usaha
  • Nama toko / usaha
  • Username (dibuat sendiri oleh pengguna)
  • Password (disimpan dalam bentuk terenkripsi — tidak dapat dibaca)
  • Peran pengguna (Admin, Supervisor, Kasir)

b. Data Bisnis

Data yang diinput pengguna untuk keperluan operasional bisnis:

Jenis Data Contoh Tujuan
Data Produk Nama, harga, kategori, foto produk Ditampilkan di kasir (POS)
Data Transaksi Item terjual, jumlah, metode bayar, waktu Riwayat penjualan & laporan
Data Pelanggan Nama pelanggan (opsional, jika diinput) Struk & catatan transaksi
Pengaturan Toko Nama toko, alamat, logo, foto QRIS Ditampilkan di struk
Data Keuangan Daftar akun (kas, bank, pendapatan, dst.) Laporan keuangan sederhana

c. Data Teknis

Data yang dikumpulkan secara otomatis saat menggunakan aplikasi:

  • Token autentikasi JWT (disimpan di perangkat untuk sesi login)
  • Waktu transaksi (timestamp)
ℹ️ Kami tidak mengumpulkan data lokasi, kontak perangkat, riwayat panggilan, atau data sensor perangkat Anda.
🎯

2. Cara Kami Menggunakan Informasi

Data yang dikumpulkan digunakan semata-mata untuk:

  • Menjalankan fitur aplikasi kasir (POS, manajemen produk, laporan)
  • Memverifikasi identitas pengguna saat login
  • Menyimpan riwayat transaksi dan laporan keuangan
  • Mencetak atau mengunduh struk pembayaran
  • Menampilkan data yang Anda input di berbagai halaman aplikasi
ℹ️ Kami tidak menggunakan data Anda untuk iklan, profiling, atau keperluan di luar operasional aplikasi kasir.
🔒

3. Penyimpanan & Keamanan Data

Lokasi Penyimpanan

Seluruh data bisnis Anda (produk, transaksi, akun, pengaturan) disimpan di server pribadi yang Anda kontrol. Kasir Online beroperasi dengan model self-hosted atau dedicated server per tenant — data Anda tidak bercampur dengan pengguna lain.

Keamanan

  • Password dienkripsi menggunakan bcrypt (hashing satu arah — tidak dapat didekripsi)
  • Komunikasi antara aplikasi dan server menggunakan protokol HTTPS
  • Autentikasi menggunakan JSON Web Token (JWT) dengan masa berlaku terbatas (8 jam)
  • Akses data dibatasi berdasarkan peran (Admin, Supervisor, Kasir)

Retensi Data

Data Anda disimpan selama akun Anda aktif. Jika Anda menghapus akun atau menghentikan layanan, data dapat dihapus permanen atas permintaan Anda.

⚠️ Keamanan data juga bergantung pada kekuatan password yang Anda gunakan. Gunakan password minimal 8 karakter dengan kombinasi huruf dan angka.
🤝

4. Berbagi Data dengan Pihak Ketiga

Kami tidak menjual, menyewakan, atau berbagi data pribadi Anda kepada pihak ketiga untuk tujuan komersial.

Data Anda hanya dapat dibagikan dalam situasi berikut:

  • Atas permintaan Anda sendiri — misalnya mengekspor laporan atau struk
  • Kewajiban hukum — jika diwajibkan oleh peraturan perundang-undangan yang berlaku di Indonesia
ℹ️ Aplikasi ini tidak menggunakan layanan pihak ketiga seperti Google Analytics, Firebase, Facebook SDK, atau jaringan iklan apapun.
✅

5. Hak Pengguna

Sebagai pengguna, Anda berhak untuk:

  • Mengakses data — melihat semua data yang Anda input melalui antarmuka aplikasi
  • Mengoreksi data — mengubah informasi akun, produk, atau pengaturan kapan saja
  • Menghapus data — menghapus produk, transaksi, atau akun pengguna melalui aplikasi atau dengan menghubungi kami
  • Ekspor data — mengunduh laporan dalam format yang tersedia di aplikasi
  • Menonaktifkan akun — Admin dapat menonaktifkan akun kasir/supervisor kapan saja

Untuk permintaan penghapusan data secara lengkap (termasuk data server), silakan hubungi kami melalui kontak di bawah.

🧒

6. Data Anak-anak

Aplikasi Kasir Online ditujukan untuk digunakan oleh pelaku usaha dewasa. Kami tidak secara sengaja mengumpulkan data dari anak-anak di bawah usia 13 tahun.

Jika Anda mengetahui bahwa anak di bawah umur telah mendaftarkan akun tanpa izin orang tua, segera hubungi kami untuk menghapus data tersebut.

🔄

7. Perubahan Kebijakan Privasi

Kami dapat memperbarui kebijakan privasi ini dari waktu ke waktu. Setiap perubahan akan dicantumkan di halaman ini dengan tanggal pembaruan yang baru.

Jika terjadi perubahan yang bersifat signifikan, kami akan memberikan pemberitahuan melalui aplikasi. Kelanjutan penggunaan aplikasi setelah pemberitahuan tersebut berarti Anda menyetujui kebijakan yang diperbarui.
